## Запуск

Сборка образов и запуск:

```shell
DOCKER_BUILDKIT=1 COMPOSE_DOCKER_CLI_BUILD=1 docker compose build
docker compose up
```

`localhost:8080`

Сброс тома с базой данных:

```shell
docker compose down --volumes
```
